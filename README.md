# Norm Free CRM

Бесплатный standalone CRM, вдохновлённый публичным набором возможностей Norm CRM. Это самостоятельная реализация, а не копия исходного кода или закрытой части сервиса.

## Запуск
Просто открой `index.html` в браузере. Данные сохраняются локально в браузере через localStorage. Для резервной копии используй «Экспорт».

## Уже есть
- обзор и быстрые действия
- контакты
- проекты
- задачи + Kanban
- календарь встреч
- тайм-трекер
- договоры
- финансы
- отчёты
- напоминания
- JSON экспорт/импорт
- адаптивный интерфейс

## Важно
Серверной авторизации, email/Telegram-уведомлений, PDF и общей базы между устройствами в MVP нет. Эти функции можно добавить следующим этапом через бесплатный backend (например Supabase).
